# Sinchana — Analytics Portfolio

A responsive personal portfolio website focused on showcasing analytics work, case studies, capabilities and contact details.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html`.
- Update the GitHub repository link if your portfolio repository changes.
- Add the final Tableau Public URL and real screenshots when your dashboards are ready.
- Keep planned projects labelled as planned until they are actually built and validated.
- The Revenue Intelligence Platform uses synthetic data; keep that disclosure visible.

## Publish to GitHub Pages
Upload the *contents* of this folder to the root of your `Analytics-Portfolio` repository. `index.html`, `styles.css`, `script.js`, and `assets/` should be directly at the repository root.
