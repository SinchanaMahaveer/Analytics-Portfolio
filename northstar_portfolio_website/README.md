# Northstar Commerce — Portfolio Case Study Website

A responsive static website for presenting the Revenue Intelligence Platform project.

## Preview locally
Open `index.html` in a browser. For best results, use a local static server or VS Code Live Server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Replace the Tableau dashboard placeholder link with your published Tableau Public URL.
3. Replace the three screenshot slots in the Dashboard section with your finished Tableau dashboard screenshots.
4. Keep the synthetic-data disclaimer visible. Northstar Commerce is fictional and all project data is synthetic.
5. Review the project metrics and wording against the latest validation output before publishing.

## Files
- `index.html` — website structure and copy
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and placeholder-link behaviour
- `assets/dashboard-data-preview.png` — static preview rendered from project dashboard CSVs, if included

## Publish
This is a static site. You can deploy it with GitHub Pages, Netlify, or Vercel by uploading the folder/repository. No backend is required.
